# Localization

Both clients offer light, dark and system themes and remember language and theme choices.

The web dashboard and mobile client support English, Simplified Chinese, Traditional Chinese, Japanese, Korean, German, French and Spanish.

## Mobile

1. Edit translations in `lib/l10n/app_*.arb`. The English file is the template. Keep message keys consistent across languages.
2. Run `dart run tool/generate_localizations.dart`. It invokes Flutter's official `gen-l10n` command and generates the typed lookup used by data-driven forms.
3. Flutter regenerates the localization classes during dependency resolution. The typed form-message lookup is checked in and regenerated by the command above. Generated Dart files live in `lib/generated/l10n`. Edit the ARB resources rather than generated output.
4. The language menu can follow the system or remember an explicit choice. Flutter localization delegates handle native controls, and `intl` formats dates and numbers.
5. Verify narrow layouts and run `flutter analyze` and `flutter test` after editing resources.

## Web

1. Edit the matching JSON resource under `web/src/lib/locales` in the dashboard repository.
2. Vue I18n supplies application messages. Element Plus supplies matching localized controls.
3. The language choice is stored locally. Unsupported browser languages fall back to English.
4. Brand titles use one language at a time. Protocol identifiers and user-provided names remain unchanged.

New language translations are initial translations. Native-language review is recommended before distribution.
